## Proyecto: Discovery Server + Configuración centralizada

El servicio **Discovery Server** es un componente clave en la arquitectura de microservicios.
Su función principal es mantener un registro de todos los servicios en ejecución en la red.
Esto permite a los clientes (otros microservicios) descubrir y comunicarse con los servicios disponibles.

> [Código fuente](https://github.com/)

## Tecnologías utilizadas

- Node.js + Express + TypeScript
- Consul Server
- Docker

## Arquitectura del Sistema

El flujo del microservicio sigue la siguiente secuencia:

- Consul es una herramienta de código abierto para servicio de descubrimiento y configuración distribuida.
- En primer lugar, Consul registra las configuración de variales de entorno de cada microservicio y los sube al servidor de configuración,
  luego cada microservicio se registra en el servidor de descubrimiento.
- Los clientes (otros microservicios) pueden consultar el servidor de descubrimiento para encontrar los servicios disponibles.
- Los microservicios pueden comunicarse entre sí a través de la dirección IP y el puerto registrados en el servidor de descubrimiento.
