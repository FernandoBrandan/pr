## Proyecto: Discovery Server + Configuración centralizada

El servicio **Discovery Server** es un componente clave en la arquitectura de microservicios.
Su función principal es mantener un registro de todos los servicios en ejecución en la red.
Esto permite a los clientes (otros microservicios) descubrir y comunicarse con los servicios disponibles.

> [Código fuente](https://github.com/)

## Tecnologías utilizadas

- Node.js + Express + TypeScript
- Consul Server
- Docker

## Arquitectura del Sistema

El flujo del microservicio sigue la siguiente secuencia:

- Consul es una herramienta de código abierto para servicio de descubrimiento y configuración distribuida.
- En primer lugar, Consul registra las configuración de variales de entorno de cada microservicio y los sube al servidor de configuración,
  luego cada microservicio se registra en el servidor de descubrimiento.
- Los clientes (otros microservicios) pueden consultar el servidor de descubrimiento para encontrar los servicios disponibles.
- Los microservicios pueden comunicarse entre sí a través de la dirección IP y el puerto registrados en el servidor de descubrimiento.

```js
// index.ts
import express from "express"
const app = express()
import "./eureka-client"
import { getConfig } from "./getConfig"
;(async () => {
  const config = await getConfig("books")
  const port = process.env.PORT ? parseInt(process.env.PORT, 10) : config.port
  app.listen(port, () => {
    console.log(`Gateway - Server listening on http://localhost:${port}`)
  })
})()
```

```js
// getConfig.ts
import Consul from "consul";
const consul = new Consul({
  host: process.env.CONSUL_HOST || "consul_service",
  promisify: true,
});

export async function getConfig(serviceName: string) {
  const result = await consul.kv.get(`config/${serviceName}`);
  if (!result || !result.Value) {
    throw new Error(`No config found for ${serviceName}`);
  }
  return JSON.parse(result.Value as string);
}
```

```js
// consul-client.ts
import { getConfig, consul } from "./getConfig"
;(async () => {
  const config = await getConfig("microservicio")

  const PORT = Number(config.PORT)
  const serviceId = `microservicio-${PORT}`

  await consul.agent.service.register({
    id: serviceId,
    name: "microservicio",
    address: "localhost",
    port: PORT,
    check: {
      name: "health check1",
      http: `http://microservicio:${PORT}/api/v1/health`,
      interval: "10s",
      timeout: "5s",
      deregistercriticalserviceafter: "1m",
    },
  })
  console.log(`microservicio registrado en Consul como '${serviceId}'`)
  const services = await consul.agent.service.list()
  console.log("Servicios registrados:", Object.keys(services))
})()
```
