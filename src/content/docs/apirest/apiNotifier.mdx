# Proyecto: API Notifier

El servicio **Notifier** esta diseñado para enviar correos electrónicos de notificación y generar facturas en formato PDF de forma automática.
Obtiene la información de la orden de compra mediante una arquitectura asíncrona basada en Pub/Sub,
lo que permite una comunicación desacoplada y eficiente entre servicios.

## Características

- Envío de email de notificación con la confirmacion de la orden de compra y su información.
- Generación de facturas en PDF.
- Utiliza AWS S3 para almacenar los archivos.

## ⚙️ Tecnologías Utilizadas

- Node.js / TypeScript
- AWS S3
- RabbitMQ (Pub/Sub)
- Nodemailer
- PDFKit / jsPDF (generación de PDFs)
