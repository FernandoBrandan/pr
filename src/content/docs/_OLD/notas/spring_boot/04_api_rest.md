## Paquetes utiles
- Lombok 
- Spring Web: Endpoints para crear api rest
- Spring Data MongoDB
- Spring Data JPA : Para conectar a base de datos relacionales, mysql
- MySQL Driver
- spring-cloud-starter-netflix-eureka-client: Para conectar a Eureka server, discovery server
  
 
##  Configuracion de proyecto

- src/main/resources/application.properties
  - spring.data.mongodb.uri=mongodb://localhost:27017/bikes
