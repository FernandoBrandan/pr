He trabajado distintas tecnologias para desarrollar microservicios, integraciones con bases de datos, y manejo de autenticaciones. 
Me enfoco en la optimización del rendimiento y la escalabilidad de aplicaciones backend.
Aunque mi especialidad es el backend, mi experiencia en el frontend me permite colaborar eficazmente con equipos front, 
asegurando una integración fluida de las APIs y mejorando la experiencia de usuario final.

- Habilidades en arquitectura de software y desarrollo de sistemas distribuidos.
- Arquitectura de microservicios, basada en eventos y mensajería asíncrona.

### Descripción del proyecto:

- Desarrollé y mantuve un sistema de microservicios donde asegura la escalabilidad y flexibilidad del sistema utilizando (Node.js, Express, Typescript)
- API Gateway que centraliza las solicitudes de los clientes hacia los microservicios (Usuarios, Productos, Pedidos, Servicios)

## Tareas:

- **Diseño e implementación de API Gateway**:
  Centralicé las peticiones en un único punto de acceso, enroutando las solicitudes a diferentes microservicios,
  asegurando la correcta separacion de responsabilidades.
- **Desarrollo de microservicios independientes**: Implementé microservicios autónomos para gestionar usuarios, productos, pedidos y servicios, cada uno con su propia base de datos y lógica de negocio.
- **Automatización de pruebas de integración**: Creé pruebas de integración para garantizar que el API Gateway y los microservicios trabajen de manera eficiente y sin fallos en la comunicación.
- **Optimización del rendimiento**: Implementé técnicas de cacheo en el API Gateway para mejorar la eficiencia en la respuesta de los microservicios.
- **Manejo de errores y seguridad**: Integré mecanismos de manejo de errores y validación de seguridad, incluyendo autenticación y autorización centralizadas en el API Gateway.
- **Despliegue en contenedores Docker**: Desplegué los microservicios y el API Gateway en contenedores Docker, lo que facilitó la escalabilidad y la gestión de ambientes de desarrollo, pruebas y producción.

## Tecnologías y herramientas utilizadas

- JavaScript, Node.js, Typescript, Express, Spring Boot
- MongoDB, MySQL
- Docker
- Supertest
- API REST, Microservicios
